# Human review sheets

Each file is one reviewer on one trip. `rubric_version` must match the offline judge rubric. Dimensions are `relevance`, `diversity`, and `narrative`, each pass or fail, plus `free_text`.

Protocol from blueprint §11.7: at least 60 generated trips across at least 3 destinations, at least 2 reviewers per trip, a third reviewer when they disagree, pairwise pass/fail agreement at least 80% before the judge is judged. Re-review when the rubric, prompt, or model changes, and once a quarter. This folder is the format. It is not a filled 60-trip set.
